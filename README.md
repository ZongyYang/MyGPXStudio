# MyGPXStudio（macOS + iOS）

一个精简的 macOS 路线转 GPX 工具：国内地点使用高德 Web 服务，海外地点自动回退到 Apple MapKit，支持驾车/骑行/步行路线，并按指定出发时间导出带时间戳的 WGS-84 GPX 轨迹。

## 使用方法

1. 打开应用，使用 `⌘,` 打开设置，填写高德开放平台的 **Web 服务 API Key**；安全密钥可选。
2. 在起点和终点输入地点或地址，在下方结果中点选含详细地址的地点；可添加多个途经点，并用每行右侧的上下按钮调整顺序。
3. 在顶部使用驾车、骑行或步行图标选择交通方式，再设置出发时间并生成路线。
4. 有途经点时，应用会按当前顺序逐段规划并合并为一条路线；没有途经点时，如果高德返回多条路线，可在路线信息卡片中选择方案。
5. 导出 `.gpx` 文件；也可以从“文件”菜单选择“合并文件夹中的 GPX…”合并已有 GPX 文件。

如果起点和终点是同一个地点，至少添加一个途经点，应用会按“起点 → 途经点 → 起点”规划环行路线。生成路线按钮不可用时，按钮下方会显示具体原因，例如哪个途经点尚未选定地点。

API Key 仅保存在本机系统钥匙串。高德结果的 GCJ-02 坐标会转换为 GPX 标准的 WGS-84；Apple MapKit 结果本身使用 WGS-84。每个轨迹点按路径距离分配预计时长。

## iOS 版本

`MyGPXStudio-iOS.xcodeproj` 是独立的 iPhone/iPad Target，提供原生 MapKit 地图、起点/途经点/终点管理、路线生成和 GPX 系统分享。路线规划卡片使用可上下拖动的系统底部抽屉，支持收起、半屏和全屏展开。首次使用时在 App 右上角设置中输入高德 Web 服务 API Key；密钥只保存到本机钥匙串。

## 构建

在此目录运行：

```bash
swift build -c release
```

产物为 `.build/release/RouteToGPX`。可用项目内的 `build_macos.sh` 打包为 `.app`。

完整的功能说明、文件结构、交接和后续开发注意事项见 [MyGPXStudio-开发记录.md](MyGPXStudio-开发记录.md)。
